# fila documentation

- [Specification](specification.md): what `fila` does and how. Concepts,
  nodes and their registration, the architecture, jobs and their states,
  resources and how limits are enforced, scheduling, Slurm clusters, failures,
  files, the command line, agents and security. The source code cites it by
  section.
- [Releasing](releasing.md): the public interface, versioning and the release
  procedure.
- `fila --help` and `fila <command> --help`: every option of the command line.
- `fila guide`: the usage guide for agents (section 12.1 of the
  specification).
